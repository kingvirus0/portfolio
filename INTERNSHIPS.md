## 🎖️ The 5 programs most likely to accept you (ranked)

### 1. GitHub Octernships — *fully remote, paid* 🎯 BEST FIT
- **What:** Real projects with industry partners ($500+/mo stipend), open-source mentoring
- **Eligibility:** Verified student on Global Campus + active GitHub contributor + enrolled in institution with work eligibility in **Nigeria** ✅
- **Where:** [education.github.com/globalcampus/octernships](https://education.github.com/globalcampus/octernships)
- **Action:** Verify Global Campus → watch the Octernship board → apply to posted projects

### 2. Outreachy — *$7,000 stipend, fully remote* 💰 
- **What:** 3-month paid open-source internship for people underrepresented in tech (Africans count). Dec 2026 round incoming.
- **Timeline (Dec 2026 round):** Initial applications **open now (~Aug 2026)** → contribute to projects late Sep–late Oct → internship Dec–Mar
- **Need:** 42 consecutive days free from school; must make ≥1 open-source contribution to apply
- **Action:** Create Outreachy account → fill initial application *this month* → reserve 42 days
- **Where:** [outreachy.org](https://www.outreachy.org/)

### 3. Google Summer of Code — *remote, global, paid*
- **What:** 12-week open-source coding program, $1,500–$3,300 stipend, 123 countries
- **Timeline:** Org list announced **Feb** → proposals **March 16–31** → coding May–Aug
- **Action:** Start contributing to candidate orgs' projects *now* (contributions before applying massively boost acceptance)
- **Where:** [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com/)

### 4. UNDP Digital, AI & Innovation Internship — *remote, paid* 🌍
- **What:** 3-month remote UN internship, $200–500/mo stipend, areas incl. Data Analytics, AI product design
- **Deadline:** **September 30, 2026** (rolling — apply early)
- **Eligibility:** Students or recent graduates in CS, data science, AI, or related
- **Action:** Apply before Sep 30
- **Where:** careers.un.org / search "UNDP AI Innovation Internship 2026"

### 5. LFX Mentorship (Linux Foundation) — *remote, paid*
- **What:** Rolling paid mentorship on CNCF/Linux Foundation projects
- **Where:** [lfx.linuxfoundation.org/mentorship](https://lfx.linuxfoundation.org/mentorship)
- **Action:** Browse project list, apply — has AI/data projects
